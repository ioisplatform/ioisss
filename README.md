# IOIS PLATFORM
Indian Online Income Supporting System — बदलते भारत की शान

This package keeps the existing IOIS premium home-page theme and connects the website to the centralized Supabase authentication/data architecture.

### Included
- Premium single-page home theme
- Membership plans
- Register / Login / Reset password
- Supabase Auth
- Automatic profile + member creation trigger
- Dashboard
- Payment submission
- Admin pages
- ID Card / Certificate pages
- Panchang / Weather / Jobs / News / Downloads / Chat / Contact
- Telegram notification Edge Function template
- Supabase SQL schema + RLS

See `DEPLOYMENT.md` before publishing.
